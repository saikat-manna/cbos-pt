User Tasks (✋ Human)
• Create / Edit documents
• Approve / Reject / Return
• Share to counterparties
• Accept terms & documents
• Upload external docs (BL, COO, FIRC)
• Confirm payment advice
• Submit to customs / bank
System Actions (⚙ Auto)
• Convert PI → CI Draft
• Capture LC rules
• Link docs to trade/shipment
• Emit payment ready signal
• Reconcile payment to CI
• Map FIRC & close EDPMS
• Auto-transition terminal states
Validations (◆ Decision)
• V = Field validation (single doc)
• X = Cross-doc check (vs reference)
• T = Timeline/deadline check
• PASS = proceed to next state
• FAIL(400) = block + return errors
• WARN(200) = proceed + warnings[]
Fork-Join Parallelism
• Fork 1: PI ‖ PO (negotiation)
• Fork 2: PL ‖ SI (pre-shipment)
• Fork 3: BL ‖ COO ‖ EXD (shipment)
• Sequential: CI (from PI)
• Sequential: IMD (from BL+COO+CI)
• Sequential: PA → FIRC
